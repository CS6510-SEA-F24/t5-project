# Feature Status

## Implemented Features

- **YAML Pipeline Configuration Parser**
    - Parses and validates YAML files for CI/CD configurations, recording the start line number of each job.
- **HTML Visualization Generator**
    - Generates HTML representations of YAML configuration files.
- **Job Dependencies Visualization**
    - Visualizes dependencies between different jobs in the pipeline.
- **Artifact Tracking**
    - Tracks and displays artifacts generated by various jobs.
- **Stage-based Layout**
    - Organizes jobs into distinct stages with customizable spacing.
- **Custom Output Design**
    - Allows users to customize the output via CLI, including specifying the output HTML file path, selecting a visual theme (light/dark), setting the gap between stages in pixels, and choosing to delete generated files after creation.
- **Syntax Highlighting with Pygments**
    - Implements syntax highlighting for YAML content using Pygments and enables navigation to specific lines in the YAML view via URL hashes.
- **Responsive Design**
    - Ensures the visualization is responsive and visually appealing across different screen sizes and devices.

## Partially Implemented Features

- **Interactive Features**
    - Basic interactivity is implemented, such as clickable job links that navigate to the YAML view.
- **Dynamic Updates**
    - Limited support for dynamic updates; future enhancements are needed to support real-time changes.
- **Error Handling and Feedback**
    - Displays basic error messages; more comprehensive feedback mechanisms are planned.

## Planned Features

- **External CI/CD System Integration**
    - Integrate with external CI/CD systems for seamless pipeline management.
- **Advanced Interactive Features**
    - Enhance interactivity with features like drag-and-drop job reordering, real-time collaboration, and interactive tooltips.
- **Enhanced Error Handling**
    - Provide more detailed error messages and validation feedback to users.
- **Theming and Customization**
    - Allow users to further customize the appearance of the visualization with additional themes and styles.
- **Export and Sharing Options**
    - Enable exporting the visualization in various formats and provide easy sharing capabilities.
- **Performance Optimizations**
    - Optimize performance to handle large and complex YAML configurations efficiently.
